ABOUT

西荻窪駅徒歩5分。薪窯焼きピッツァのお店です。

薪窯で一枚一枚、心を込めて丁寧に焼き上げたナポリピッツァを、広々とした飾らない空間でゆったりと…。

本場ナポリでは、ピッツァは庶民の食べ物で、日本より身近な存在です。

日本でもピッツァがそんな存在になれるように。

ここでしか味わうことのできないマルコのピッツァをお楽しみください。
