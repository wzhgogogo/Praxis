ニュージーランド産のビーフとラムを東京タワーが見える都会の中心で楽しめる場所

大人な雰囲気の店内ではニュージーランドの豊かな自然で育ったビーフとラムの炭火焼きを堪能できます。著名食評論家に「日本一のラム」と絶賛されたWAKANUIのラムチョップの他に、グリーンマッセルのワイン蒸し、キングサーモンの温燻製、ニュージーランド産のビーフといったこだわりの料理を多数用意し、様々なシーンで楽しめるように料理をご用意しています。またワインは99%がニュージーランド産で、WAKANUIが独自に厳選し輸入しています。
