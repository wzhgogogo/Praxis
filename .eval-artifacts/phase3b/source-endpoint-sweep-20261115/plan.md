# 两来源已用公开GET路径去重检查
用户要求把之前用到的两个网站都试一遍。固定a66a2edc，公开D02-V与D8历史HAR为输入，选取23项代表去重路径，具体URL和出处在manifest。两个来源先各加载一个原入口；后续自然加载过且200的路径复用本轮状态，其余逐项GET，间隔至少5秒，单请求20秒，不重试。全部通过原浏览器工厂/代理及原Guard，不放宽准入。独立上限0Live/25评估GET/0模型/0环境重跑，实际按发送计费。

检查包含页面、菜单、条款、关键词联想、4种空位相关读取、TableCheck catalog/search/geolocation/shop、两家静态CDN。历史脚本哈希版本、不同店铺同类页面不穷举。保留全部失败和Guard拒绝。只记录状态、耗时、正文大小与哈希。源码不改，旧账本不动。

浏览器fetch用于录制URL的HTTP连通检查，资源类型和原生页面交互可以不同，所以与原生首轮加载结果分别汇报。只读响应会有一次性GET、公共API可能返回业务4xx、或浏览器CORS限制；这些须分别归因，不把HTTP可达当成功查位。曾用availability_calendar_v2缺原始查询值，保留来源缺口，不补造参数、不用不完整请求冒充验收。预约/确认/登录等受限路径不执行。此轮不运行产品Live或真实模型。
