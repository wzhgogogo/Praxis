## 2 实现及不变量

- 只在缺少同名入口且计划含后续结构化来源时，提前读取该计划的同一 Google 批次；共享文本规划仍只做一次。读取及失败都保存在 Domain 的 opaque 计划中，到原 Google 阶段消费一次；持久化序列化后不重复调用。失败保留明确原因，不新增重试。
- 仅取原半径内、有有效坐标且 Pack 确认可直达的门店指针，按距离取最近者。Pack 用既有规范化语法判断观察到的地区 URL 是否为该门店 URL 的父路径。所有代码没有地点/车站/地区代码表，没有生成未观察 URL。
- Agent 仍选择**当前可操作引用**；不支持该指针的入口和全国/根列表别名不提供 OPEN_LINK，返回时再拒绝绕过。可见的更具体同源子区未进入前，不把较大父区宣布完成。LOCATION 继续只能填权威名称，且须观察输入/结果更新。
- 指针只支持地区路由，不证明餐厅身份、HARD 或库存。详情身份、精确坐标、4/5 越界换区一次、不重访、日期人数和只读权限保持原规则。
- 本切片沿用 ADR-0040 的来源观察引用、Pack grammar 和 Agent/Executor 分工；传入的是已有原始公开 URL，不提供地点-code 表或猜造 code，ADR 不改。
- `source-packs.ts` 相对基线新增/删除各 8 行，净增 **0**；复用了规范化函数，并移除同地区恢复中已被精确路径等式涵盖的重复前缀检查。共享执行器没有新增站点 URL 或地区常量。
- Restaurant State **17** / TaskDefinition **15**（保存提前读取），Browser Prompt **17** / action schema **11**。所有当前调用方/Fixture 同步；无旧路径兼容层、无数据库重置。Semantic、Gold、来源/全局预算未改。

## 3 检错、生产接线和独立评价

历史故障属于**旧覆盖遗漏**：原测试覆盖引用、半径、地区循环和 LOCATION，但没有“同名标签缺席、同源门店链接已经提供地区”的成功控制。`red.log` 在未修代码上既拿不到受控可行结果，也放行强行进入错误地区的动作。

| 失效机制 | 复用/补强入口 | 结果及边界 |
|---|---|---|
| 行政区/相近名称猜错第一入口 | `directory-region-selection.test.ts`；现有 Browser Fixture 中的 P21c | 神乐坂/中目黑在原 4 地区页、90 秒内取得受控结果；错误入口零执行 |
| 原批次重复读取或跨 run/请求借用 | 同一地区主测试 | 原阶段只消费一次；序列化恢复、改变请求/run、失败不重试均核对 |
| 外域、无坐标、越界或非法 URL 误作证据 | 同一地区主测试及 Pack grammar | 拒绝作为地区指针，原半径未扩大 |
| 四个对照退步 | 实际 `createLiveReadAssembly` + Guard + 本地 Chromium/HAR + 原始 Google 指针投影 | h001、KF-H005、吉祥寺、H002 均取得受控结果；H002 仍完成原三段入口路径 |

受控输入取 B 修正的六例地区观察；去除菜系/日期/人数以隔离地区问题，来源菜单是**真实观察链接投影**，详情为**合成已知可行控制**。这不是完整 HAR 录制回放，也不证明真实模型或实时库存。

`composition-results.json` 是生产组装实际输出；`evaluate-composition.py` 不导入生产 matcher，按冻结的字面地区预期、独立距离计算、原始 Browser 观察引用/实际快照 URL 和预算核验，输出 `composition-evaluation.json`。初次诊断用 session.navigate 调用列表代替全部浏览器导航，造成观察证据误报；保留 initial 产物，改采实际 snapshot URL 与决策前引用，未改变 Gold 或门槛。早期本地 Fixture 另捕获并修复全国列表别名被当作同地区恢复入口的问题；诊断日志保留，不算基线故障红灯。
