## 输入、答案与范围修订

原始 153 个 browser_read_decide 中，按 AVAILABILITY、目标 2026-11、观察有 2026-10 日期格且有 Next 得到 104 点。主样本取其中原决策明确选择 Next 的 69 点：c-01/02/03/04/05 分别 19/17/16/1/16；其余 35 点保留清单。重复决策不去重，各变体各调用一次，共 276 次。用户将调用硬上限从 200 提高至 300；失败调用也计数，余下 24 次不自动使用。

原复核规则“日期格前的 Next”经已保存 HTML 独立核查错误：主样本中 59 点为 time-select-next、10 点为 headcount-select-next。真实翻月节点是含 Next month 文本的日历导航链接，原观察已有其引用，但 label 为空。示例 c-01 sequence 28：131 是人数 Next，136 是时间 Next；真实翻月为 90（空标签 LINK，允许 CLICK）。最初沟通称真实控件未进入观察不准确，现按原始 CONTROLS 与 DOM 的对应关系纠正，旧复核文件不改。

用户已明确选择“将 V3 扩为补齐真实翻月控件，并按真实控件评分”。本批答案以原 HTML 中真实节点及其原始 targetRef 为准，不采用位置规则。V3 补全已有空标签链接的公开 DOM 文本，无需新增引用；全部变体保留原控件顺序、引用和允许动作。答案单独保存，不放入模型输入。

运行前提交脚本、输入、独立答案、顺序与参数，SHA-256 清单校验；运行中不改。阶段累计账本基线 1718/4000 模型、7/100 完整 Live、0/10 正式环境重跑，本批回放调用追加扣账。每个逻辑请求在调用前写不可覆盖开始凭据，至多一次；无自动重试。只允许 POST 到 DeepSeek 的 beta/chat/completions，拒绝重定向；不导入或执行浏览器 Runner，不做来源预检。

硬上限 300 且不得越过阶段剩余额度；本计划只含 276 请求。鉴权/配置类 HTTP 400/401/402/403 或连续三个传输/服务错误停止，未到达项保留。语义选错不停止。中断、错误、缺 token 的分母分别报告，不补零，不暗中补跑。
