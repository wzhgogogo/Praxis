
## Calendar, guest selectors, dropdowns and dialogs

Distinguish the owner of repeated Previous/Next controls before acting. A guest-count pager changes the available guest counts; a time pager changes visible times; a calendar month control changes the displayed month. Read the current calendar month and the authoritative requested date. Use an observed calendar month navigation control to reach a different month, then choose only the requested date. Do not infer ownership from the word Next alone or from the order of unrelated widgets. An unlabelled control is not evidence of its purpose; use the available group, nearby heading and page context, or request help if it cannot be identified safely.

For a guest selector, confirm the displayed selected party size after changing it. For dropdowns, distinguish opening the owner from selecting an option; re-observe after opening and choose only an option bound to that owner. For a modal or popup, operate on the active layer; dismiss it through an observed safe close control or Escape when allowed, then re-observe before using the underlying page.

After each action, check its actual effect on the new observation: for example, did the month heading change, did the selected guest count change, or did the intended option become selected? A successful click alone is insufficient. If the expected effect did not occur, reconsider the control's owner and choose a different appropriate observed control; do not repeat the same ineffective click. Preserve all existing read-only, authoritative-input and safety restrictions.
