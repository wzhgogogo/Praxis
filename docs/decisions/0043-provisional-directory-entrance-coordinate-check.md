## Context

固定 `3ec38584` 的 D1/D2 例 01 诊断中，英文菜单未出现 Akabane 入口，当前候选也无可用同源店铺指针。模型选择的地区标签无法通过 `namedEntrance`，地区完成之前不能进入详情取样，两次 Tabelog 详情均为 0。旧首五家 4/5 规则尚未取得样本，所以只调整五家数量条件不能解决该失败。

用户已选择方案 A、拒绝 B；停止点 1b 复核后进一步裁定只做 A，并直接批准本次修订的 ADR。批准的是设计，尚未实现；本批仍须停在 1c。原 ADR-0040／0042 正文和历史状态不改，不把任何条款标成已替代。

Q7 已证普通车站链接与类别入口出现、普通 OPEN_LINK 已提供，未证明共享层漏掉支持权威地点的可用控件，拿不到该修复的有效红灯。因此 LOCATION／车站路线未采纳，等 F5 Live 有完整 DOM 证据后再议；本批不启动该 Live。原五页问题通过复用本来源流程已观察入口直接导航解决，不能靠加页或放开陈旧 DOM ref。

## Decision（用户已批准；尚未实施）

1. **临时入口。** 请求有权威地点名，模型选择已观察地区入口，其标签不含请求地名且没有同源店铺指针时，允许将它标记为临时入口。已有权威 LOCATION 确认按既有路径处理。代码仍核对来源、入口与当前页面的一致性、当前可解析的公共列表；模型 COMPLETE 不构成完成依据。不能把全国／东京导航菜单、未加载或解析失败页当作列表，也不能因标签无法绑定而永远阻止取得详情坐标。空列表不提供有效坐标样本，不能认证全地区无店。

2. **两有效样本。** 临时入口按原详情队列取样，去重并在每次得到有效详情坐标后判定。前两个有效样本均在原半径外时允许换入口一次；任一家在半径内即核实该入口，按原流程继续。缺坐标、无效坐标、未知身份或无法计算距离的样本不计入两个有效坐标，也不当作越界或合格；已经开始的详情仍消耗原额度。不为凑样本增页、重读详情或增加时间。

3. **距离与方位反馈。** 只由代码用详情页同店 JSON-LD 的有效坐标和冻结的权威圆心计算距离、圆心指向店的初始方位角与可读方向，附详情／样本引用。资格以未舍入距离判定；展示可舍入。下一次既有换入口观察提供每个有效样本的距离、方位、内外判定与剩余预算；未知单列。模型不得修改计算值、圆心、半径、用户地点，也不能为解释方位增加模型／Google／地图调用。

4. **一次总上限与保留候选。** 两样本触发与 ADR-0040 首五家中 4 家越界共用整个地区发现流程唯一一次换入口额度。不得按规则、批次、继续流程或来源作用域重建而刷新。具名、已确认 LOCATION 或同源指针入口不进入临时分支；保留其原首五家规则和正常行为。临时入口核实后按原流程继续，不能由另一规则获得第二次纠正。已接纳且身份／请求有效的候选及去重记录保留；核实入口不证明 HARD 或库存满足。

5. **立即收尾。** 第二入口依同一两有效样本规则仍被证实越界，或本来源流程已观察集合没有预算内可用的不同替代入口，立即结束本来源地区流程；集合为空不再调用模型找菜单。来源 90 秒或其他原预算耗尽时同样停止。非法／跨来源／流程选择在导航前拒绝，以非法选择原因 UNKNOWN，不能谎称集合为空或自动多问一次。保留已接纳候选，来源记 UNKNOWN 并附可观察原因，移交下一既有来源；全局预算／取消则按原全局停止合同。禁止回全国或东京菜单继续寻找，不增加第三入口或恢复重试。

6. **误判代价有界。** “正确区域、圆心在区域边缘、前两家恰好越界”可以使取样误判。代码在运行时不知道区域其实正确，不新增识别此误判的逻辑或原因码；只按第二入口仍外／无替代等可观察事实收尾。用本地构造且由独立 oracle 标注的控制输入证明：误判只用掉一次换入口，已接纳候选保留，剩余预算不重置。不能以“补偿误判”为由恢复入口搜索。

7. **已观察集合、直接替代与预算。** 替代入口取自同一 Task／run、同一来源流程实际观察到并通过当前 Pack `isRegionEntrance` 的 LINK href 集合，保留原页面、observation revision、targetRef、标签、精确 href 和来源／流程作用域。不能跨来源／流程复制、按标签生成或改写 href。代码把合法候选集合与 A-1 距离方位反馈、剩余预算及更换次数一并交模型；模型只选择一个集合引用，代码核对成员资格、作用域、Pack、不同入口、Guard／origin 和预算后直接导航，记录原观察引用，**不读恢复菜单页**。地区页仍最多 4 页：D1 东京(1)→A1322(2)→A132201(3)→替代(4)。直接 NAVIGATE 必须计入原页数，不能漏计或重复计。每来源 10 详情／90 秒、整单 500 秒／50 模型、检索 3 页／列表总额 7 页均保持；原计数、改写次数和截止时间不重置。集合跨同来源批次保留时与请求和累计进度一起绑定，经原 Event／Reducer 路径接纳，模型不写 State。不新增来源映射、站点代码、网络权限或兼容路径。

8. **LOCATION／车站路线：未采纳，暂缓至 F5 Live 有完整 DOM 证据后再议。** 当前没有共享层漏掉可用控件的证据，也拿不到有效红灯，不修改该能力。约束保留：站码、类别码和 URL 只能来自实际观察，模型和代码均不得拼造；不将错误地区的八站重命名为请求地点，不加站点词典或放宽 Guard。以后重议仍须明确观察与合同，本批不运行 Live。

9. **不变的接纳与职责。** 精确半径、同店身份、HARD、日期／人数／餐段、新鲜度和来源事实门槛保持。模型仅提出观察绑定动作，代码决定地区完成、坐标判定、候选接纳、预算及 UNKNOWN；不直接改变 Task State，不执行外部写操作。关键词仍按 ADR-0042，不能混入地点。店名解析归 3b，OPTIONS 和空查询后自动通用列表交 F3 审计，不在本切片改动。

10. **受限入口选择合同必须显式增加。** 当前 `browser-task-executor.ts:710–715` 只接受当前 observation 的 targetRef，普通 OPEN_LINK 还需要当前 DOM controlId；旧引用会被拒绝。实施时增加独立的集合引用选择动作（拟名 `SELECT_REGION_ENTRANCE`），仅在 DISCOVERY 的一次地区纠正阶段可用，模型不提供 href。更新 `browser-action-decision.ts` 的动作／strict wire／输入 context／Prompt、`browser-task-executor.ts` 的 skill 输入／选择结果／分派，来源组合与 `contracts.ts` 的进度／诊断字段同步；按实施时实际受影响对象递增版本。普通 DOM 动作保持 stale-ref 限制，不将旧引用伪装为当前目标，不用通用 navigate 绕过成员校验。来源 Pack 校验留在来源组合，Browser 层不依赖具体 Pack；所有动作仍共用原 Executor 预算。该合同尚未实现，本批没有 Schema／Prompt／代码变更。

## Consequences

可以在缺具名标签／指针时取得用于地理核对的证据，避免地区完成谓词与坐标取样互相等待。代价是原预算内最多两个有效样本的读取，以及一次有限纠正；坐标未知可能消耗更多原详情额度，仍不能突破上限。误判正确区域可能损失发现机会，但不会重复换区、丢弃已接纳候选或制造穷尽性结论。

历史时间拼接仅作估算：D1 第二层入口观察 38.250 秒＋两详情代理 6.872 秒＋一次选择代理 2.095 秒＋直接导航／列表观察代理 4.551 秒＋关键词代理 5.744 秒＝**57.512 秒，余 32.488 秒**。不再恢复菜单，实际地区页为东京→A1322→A132201→替代共 4 页。代码必须把直接 NAVIGATE 纳入原页额，而非只计 OPEN_LINK。

列表能否解析、替代是否对应圆心仍未证；关键历史 HTML 仅 head／缺失，不能以预算算术认证成功。保守加上 D1 作用域边界差额后约 59.493 秒；代入 D2 较慢的选区和一次决策约 87.501 秒、仅余 2.499 秒，时间紧张。第四页仍需更深菜单、没有有效替代或超时时按 UNKNOWN 收尾，不增加第五页、重读菜单或扩预算。LOCATION／车站路线不属于当前实现范围。

## Alternatives considered

- **方案 B：权威地名进入关键词，并修改空结果后的通用列表行为。拒绝。** 地名进关键词与 ADR-0042 当前边界冲突；字符串地点弱于详情坐标，例如“赤羽”可能命中“赤羽橋”；同时捆绑第二项检索行为改动，无法归因。自动改读通用列表单列 F3 审计候选，不随 F5 实施。
- 只把首五家阈值改成两家：仍无法越过 D1/D2 的地区完成前置条件，拒绝。
- 猜车站／类别代码、扩地点表或扩圆：违背观察绑定和权威地理边界，拒绝。
- 多次换入口、重置预算或为误判补偿重试：不能约束错误路径成本，拒绝。
