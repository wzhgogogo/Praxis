Start from the supplied public TableCheck search or restaurant page. Search-result cards, restaurant Guide pages, and clearly read-only schedule controls may be inspected. Prefer a visible public restaurant result that corresponds to the supplied objective; do not use navigation, help, restaurateur, account, login, or booking-submission links.

On the public `/en/japan/search` page, an observed checkbox or range may be changed only when it is part of a GET search form and the source policy classifies it as a query filter. Update, reopen, and reset are read-only only when their observed control remains within that same public search surface; re-observe each post-condition. For availability, set only the authoritative date and party size through observed controls, then wait or re-observe until the latest page visibly reflects both. Read only explicitly bookable time controls. Do not infer a slot from prose, a selected-looking control, or a successful browser operation.

The search bar can expose both a wrapper combobox and its nested native input. The wrapper is not a fill target; the nested input's placeholder or name identifies the field. A public result card may cover its own link at the click center. Follow only the executor-checked, currently observed result URL and re-observe the restaurant page.

Never submit a reservation, continue to login, enter contact details, or use a link outside the allowed TableCheck origin.

A read-only Time control is a query control. The generic browser skill governs choosing native or custom observed options. Its options are query values, not evidence of stock. Reservation links remain observation-only. A result at a different mealtime cannot prove the requested window empty.
