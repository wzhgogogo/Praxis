# Tabelog Public Read

Use only the supplied public Tabelog search and restaurant pages. Open only observed public links relevant to the stated objective: restaurant results, listing categories, query-filter removal, and result pagination. Treat challenge pages, external reservation providers, login, and booking paths as stop conditions; do not bypass a challenge or follow an external provider.

Checkbox/range changes require an explicit source-owned query contract; GET form structure alone is not permission. When a public Tabelog availability surface has observed date and party controls, set only the authoritative values and re-observe before reading explicitly available time controls. Do not treat rankings, reviews, restaurant names, or prose times as identity or availability evidence.

Never submit a reservation, enter personal details, or navigate outside the allowed Tabelog origin.

On an observed public listing search input, Discovery may fill only the supplied retrieval expression. Re-observe the current page and use an observed public query control or current result; never use the field to change the area, HARD criteria, date, party size, or time.

During Tabelog Discovery, when the page shows Search by category, click the currently observed `All` link to expand the category menu and re-observe its choices, even if that entry has controlGroupLabel `Unlabelled group`. After following a category link, the collapsed entry may display the current category instead: reopen that observed category entry to inspect its finer choices. Do not use `More filters` or a control opening an auxiliary filter dialog as the category-tree entry or as a substitute for finer categories. If an expanded category menu lacks the exact retrieval expression but offers an unexplored relevant parent or catch-all category, follow that observed category link and inspect its finer choices; do not repeat an already selected parent or toggle an unrelated filter. Close an unusable dialog with its own visible close control before interacting with the page behind it. Keep the authoritative area. A category is only a discovery lead; it does not establish that any restaurant satisfies a HARD criterion. Follow only an observed next-results link for pagination.

The source may label nonstandard calendar controls as `Date YYYY-MM-DD` and guest controls as `Guests N`. These are source-observed control labels, not values invented from the goal. Use CLICK_AUTHORITATIVE only for an exact requested value that is currently observable and offers that action. When that value is not yet available, use ADVANCE_TO_AUTHORITATIVE only on an observed control that actually advances the unconfirmed date or guest choices, never a restaurant-information link or an unrelated section, even if availableActions advertises advancement there. Every ADVANCE_TO_AUTHORITATIVE action must include valueGroupRef: copy the controlGroupRef of the observed date or guest choices being advanced. This is the value group's reference, not necessarily the advancing control's group; distinct calendar groups can have the same label. Choose the group containing the actual field choices. If no date or guest value group is observed, request human help rather than omit valueGroupRef or borrow an unrelated group's reference. When advancement exposes the exact requested value, choose it using its offered CLICK_AUTHORITATIVE action. Selected query controls and visible time choices alone do not establish bookable inventory.

Wait for a visible selectable date and an enabled visible guest control on the current calendar. Hidden future-month dates and disabled guest controls do not make the query ready. If the source reports that the current guest query cannot be adjusted, stop with a source-control limit; do not infer no availability for the requested date.

The observed English calendar time buttons navigate into booking forms. They are evidence-only; do not click them to inspect availability. Source-owned verification reads only captured public vacancy-query responses with matching merchant/date/party/time.
